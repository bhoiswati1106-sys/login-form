# 🔐 Login Form

A responsive login form built using **HTML5 and CSS3**.

## 🚀 Features

* Google and Apple login options
* Email input field
* Password input field
* Forgot Password link
* Login button
* Sign up option
* Responsive design
* Clean and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
